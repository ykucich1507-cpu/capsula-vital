# Imágenes — Hidrolavadora inalámbrica

Esta carpeta está vacía a propósito. La landing (`app/hidrolavadora/page.tsx`) usa
bloques placeholder mientras no haya fotos reales del producto.

Cuando tengas las fotos reales, subilas acá con estos nombres y activá las
imágenes reemplazando los bloques `imgph` marcados con `TODO(imagen)` en el
código por un `<img src="/hidrolavadora/<archivo>" ... />`:

| Archivo esperado | Uso |
|---|---|
| `hero.jpg` | Imagen principal del Hero |
| `uso-1.jpg` | Foto/GIF de uso real en la sección Solución |
| `galeria-1.jpg`, `galeria-2.jpg`, `galeria-3.jpg` | Galería de la sección Oferta |

Formato sugerido: JPG u WEBP, mínimo 1000px de ancho, fondo neutro o en uso real.
